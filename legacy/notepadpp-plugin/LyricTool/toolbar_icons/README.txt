LyricTools++ toolbar icons (256x256)
======================================

These are stored here just so they travel with your install -- they are
NOT used automatically. Assigning a toolbar icon to a script is a manual
step you do yourself in Notepad++:

  lyrictools_start_256.ico        -> LyricToolsPP        (green play triangle)
  lyrictools_rhymes_256.ico       -> LyricTools_Rhymes       (blue "P")
  lyrictools_nearrhymes_256.ico   -> LyricTools_NearRhymes   (orange "N")
  lyrictools_rhymereport_256.ico  -> LyricTools_RhymeReport  (purple "R")
  lyrictools_synonyms_256.ico     -> LyricTools_Synonyms     (teal "S")
  lyrictools_deepsearch_256.ico   -> LyricTools_DeepSearch   (red "D")

To use one:
1. Plugins > PythonScript > Configuration (may just read "PythonScript" on
   newer builds).
2. Select a script, click Add under Toolbar icons.
3. When it asks for an icon, browse to this folder and pick the matching
   file.
4. Repeat for each script, click OK, restart Notepad++.
